# madunacapitaltechnologies.com

The public website of Maduna Capital Technologies: one static page (`index.html`, `styles.css`, `assets/`), no build step.

Hosted on GitHub Pages with the custom domain in `CNAME`. The domain's DNS is managed in Squarespace; the website records point at GitHub Pages, and the Google Workspace email records (MX, SPF) are separate and must stay as they are.

Edit the HTML, commit to `main`, and GitHub Pages republishes within a minute or two.

This site is public: keep it at headline level (no bookmaker names, methods or model details). Those belong in the investor deck and report.
